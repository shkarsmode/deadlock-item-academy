# Deadlock Item Academy

> Don't memorize builds. Understand decisions.

**Живая версия:** https://deadlock-item-academy.vercel.app

Тренажёр решений по предметам Deadlock. Задача не в том, чтобы выучить чужой билд, а в том, чтобы
в матче за пару секунд понять, что происходит, и выбрать предмет, который решает именно эту проблему.

Приложение работает целиком в браузере: прогресс хранится локально (IndexedDB), аккаунт не нужен,
после первого открытия работает офлайн (PWA). Интерфейс на русском с переключением на английский,
официальные названия предметов и способностей остаются как в игре.

Фанатский проект, не связан с Valve. Deadlock, названия и иконки принадлежат Valve Corporation.

## Что внутри

| Раздел | Что делает |
| --- | --- |
| Главная | Реальные метрики: какую долю предметов твоего билда ты узнаёшь, как часто правильно выбираешь контрпредмет, что повторить сегодня. |
| Тренировка | Сессии на 3, 5, 10, 20 минут или свои. Режимы: смешанный, узнавание иконок, ситуации, активки, ошибки, герой, билд, перед матчем. Кнопка «Не знаю», активное вспоминание, чередование тем, повтор ошибки другим вопросом в той же сессии. |
| Ситуации | 181 ситуация из матчей с оценкой по нескольким критериям: несколько ответов бывают разумными, у каждого варианта своя оценка и объяснение, плюс правило на будущее и дерево решения. Есть вопросы «сначала диагноз, потом покупка». |
| Симулятор магазина | Виртуальный магазин по ситуации: бюджет в душах, цены с учётом уже купленных компонентов, покупка, отмена и продажа, оценка решения по критериям ситуации и дерево решения. |
| Активки и Imbue | Как работают активные предметы и imbue, привязка к способностям выбранного героя. |
| Build Doctor | Импорт билда из кэша игры, по id публичного билда, из JSON, вручную или с подсказками по скриншоту. Анализ экономики, порогов вложений, покрытия угроз, активок, плана покупок, сравнение билдов, влияние замены предмета, «хирургия билда». Для текущих билдов Vindicta и Graves есть ручной разбор каждого предмета (Master Your Build). |
| Курсы героев | Глубокие курсы для Vindicta (15 модулей) и Graves (12 модулей). Для любого другого героя базовый курс из данных клиента. |
| Предметы | Энциклопедия всех предметов магазина с иконками из игры, фильтры, группировка по тиру, назначению или освоению, режим изучения со скрытыми названиями. Карточка предмета: когда покупать, когда не покупать, частые ошибки, что предмет не решает, синергии. |
| Поиск по проблеме | «Меня станят», «враг лечится»: какие предметы решают проблему и почему. |
| Сравнение | Два предмета рядом, с тренировкой на различение похожих. |
| Аналитика | За 7 и 30 дней: по категориям и героям, пары предметов, которые ты путаешь, доля уверенных ошибок, успех в новых и повторных ситуациях. Без псевдонаучных «индексов». |
| Тетрадь ошибок | Путаницы, ошибочные убеждения (уверенный неверный ответ), нарушенные принципы. Закрываются, когда ответишь правильно два раза подряд. |
| После матча | Короткая рефлексия: герой, противники, проблемы в матче, покупки и сомнения, результат. Приложение подбирает ситуации и предметы под эти проблемы. История матчей не загружается. |
| Поделиться | Ссылка на подборку ситуаций для друга, без регистрации. |

Горячие клавиши: `1`-`9` выбор ответа, `0` «не знаю», `Enter` дальше, `Q`/`W`/`E`/`R` уверенность,
`/` поиск, `S` режим изучения в энциклопедии, `?` справка.

## Быстрый старт

Нужен Node.js 22.18+ или 24 (проверено на 22.22.0 и 24.14.0).

```bash
npm ci
npm start            # http://localhost:4200
```

Если `npm ci` или `npm install` падает с ошибкой arborist (`Cannot read properties of null (reading 'edgesOut')`),
это известная ошибка npm 10.9. Используй npm 11:

```bash
npx -y npm@11 ci
```

## Деплой на Vercel

В репозитории есть `vercel.json`: команда сборки, папка с результатом, SPA-перенаправления
и заголовки кэширования. Достаточно импортировать репозиторий в Vercel (фреймворк определится как Angular)
или выполнить из папки проекта:

```bash
npx vercel --prod
```

Подойдёт любой статический хостинг: отдавай `dist/deadlock-item-academy/browser` и перенаправляй
неизвестные пути без расширения на `index.html`.

Репозиторий подключён к проекту на Vercel: каждый пуш в `main` собирается и публикуется автоматически.

После нового деплоя у открытого приложения появится уведомление «Доступна новая версия», поэтому
обновления контента после патчей доходят до пользователей без очистки кэша.

## Обновление данных после патча игры

1. `npm run data:sync` скачивает предметы, героев, общие данные и список патчей с
   [deadlock-api.com](https://deadlock-api.com), иконки из зеркала ассетов, сравнивает с прошлой версией
   и пишет список изменений в `public/data/game/changes.json`.
   Флаги: `--skip-icons`, `--save-raw <dir>`, `--offline <dir>`, `--client <путь к игре>`.
2. `npm run content:validate` находит материалы, которые ссылаются на изменившиеся предметы и способности
   (через «отпечатки» в `content/pins.json`), и помечает их «нужна перепроверка после патча».
3. Перепроверь помеченные тексты, затем `node scripts/validate-content.ts --repin <id>` (или `--repin all`).
4. Закоммить и задеплой.

Без нового деплоя данные можно обновить прямо в приложении: Настройки, раздел «Данные игры», проверка
обновления. Приложение скачает свежие данные, покажет изменения, пометит затронутые предметы для повторения
и позволит откатиться. Подробно: [docs/DATA.md](docs/DATA.md).

## Импорт билда

- **Из кэша игры (рекомендуется).** Файл `cached_hero_builds.kv3` лежит в
  `Steam/userdata/<твой Steam id>/1422450/remote/cfg/`. Выбери его в Build Doctor: файл разбирается
  в браузере (бинарный KV3 v5, LZ4, protobuf), никуда не отправляется. Появятся все сохранённые билды.
- **По id публичного билда.** Запрос к `api.deadlock-api.com/v1/builds?build_id=...`, отправляется только id.
- **JSON** в формате `dia-build` (пример в [docs/DATA.md](docs/DATA.md)), экспорт тоже в этом формате.
- **Вручную** или **по скриншоту**: обведи иконку на скриншоте, приложение предложит похожие предметы,
  ты подтверждаешь выбор. Скриншот не покидает браузер.

Обратного импорта в игру нет: Deadlock не принимает билды из JSON-файлов, приложение ничего не пишет
в файлы игры и не взаимодействует с её процессом.

## Как устроено обучение

Знание хранится отдельно по каждому предмету и каждому измерению: узнавание иконки, эффект, механика,
ситуации, контрпики, синергии, использование активки, решения по билду. Для каждой пары
«предмет и измерение» своя карточка FSRS (ts-fsrs, целевое удержание 90%). Уровни освоения 1-5
выдаются только за результаты: например, уровень 5 требует двух правильных ответов с первой попытки
на сложных незнакомых ситуациях без подсказок и отсутствия открытых ошибочных убеждений.

Планировщик сессии собирает вопросы по приоритету: ошибочные убеждения, путаницы похожих предметов,
нарушенные принципы, просроченные повторения, прогресс, новые предметы (с лимитом по длине сессии).
Подробно: [docs/LEARNING.md](docs/LEARNING.md).

## Известные ограничения

- Контент (разборы, ситуации, курсы) написан по данным клиента и экспертной логике, а не проверен
  игрой вживую. 154 утверждения помечены «не проверено» и видны в интерфейсе. Чаще всего это:
  как складываются несколько источников срезания лечения; считается ли урон призывов Graves
  (Ghouls, Deadheads) его уроном для вампиризма и эффектов «от урона»; прерывает ли Silence уже начатый
  channel; перезарядка зарядов Jar of Dead; детали канала Borrowed Decree; работает ли бонус Sharpshooter
  на спирит-урон пуль в Flight; что именно блокирует Deflecting Armor; как Counterspell
  и Unstoppable работают против отдельных способностей. Полный список: фильтр по метке «не проверено».
- Статистика популярных предметов берётся из deadlock-api (высокий рейтинг). Частота покупки показывает
  привычки сильных игроков, но не доказывает, что предмет лучший; в тексте это так и подаётся.
- Глубокие курсы есть только для Vindicta и Graves. Для остальных героев базовый курс из данных клиента
  и 23 общие ситуации.
- Разбор по скриншоту приблизительный: сравнение цветов иконки, каждый предмет подтверждаешь сам.
- Синхронизации между устройствами нет: перенос через экспорт и импорт JSON в настройках.
- Офлайн: приложение и данные кэшируются сразу, иконки по мере просмотра. Кнопка в настройках
  скачивает все иконки заранее (около 8 МБ).
- Симулятор повторяет логику цен магазина (компоненты засчитываются в цену улучшения), но не является
  копией его интерфейса и не моделирует лимит слотов.
- Легендарные предметы Street Brawl (T5) есть в энциклопедии (переключатель), но не в тренировках.
- Используется Angular 21 LTS, а не 22: Angular 22 требует Node 22.22.3 или новее. Переход после
  обновления Node: `npx ng update @angular/core@22 @angular/cli@22`.

## Приватность

Весь прогресс хранится в браузере. Сетевые запросы: файлы самого приложения; по желанию проверка
обновления данных и загрузка публичного билда по id через api.deadlock-api.com; иконки с зеркала
ассетов, если локальной копии нет. Аналитики и трекеров нет.
